# Examples

Prompts to try once the server is installed:

- "Get the title and duration of https://www.youtube.com/watch?v=Z5YP8kznWZs."
- "How many HuntAPI credits do I have left?"

Inspect the tools without an AI client:

```sh
export HUNTAPI_API_KEY="YOUR_API_KEY"
npx @modelcontextprotocol/inspector npx -y @huntapi/mcp
```
